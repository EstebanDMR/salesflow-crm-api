# SalesFlow CRM API

REST API profesional para la gestión de relaciones con clientes (CRM). Desarrollado con Node.js, Express, PostgreSQL y Prisma.

## Descripción
Este proyecto implementa la lógica del lado del servidor para un sistema CRM completo. Cuenta con una arquitectura por módulos e implementa las mejores prácticas de seguridad, ruteo y bases de datos relacionales.

## Scripts Principales

- `npm run dev`: Ejecuta el servidor en modo de desarrollo usando nodemon.
- `npm start`: Ejecuta el servidor en modo producción.
